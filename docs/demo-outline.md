# 演示与答辩材料大纲

## 1. 项目定位

面向企业生产管理的全栈平台：后台管理系统 + Y15智能管理平台官网。当前已具备企业基础、工程能力、安全基线、可观测性、多租户、完整工作流、实时通知与官网转化能力，可直接作为生产项目和 Vibe Coding 二次开发的基线。

## 2. 功能演示

1. 登录安全：图形验证码、登录失败锁定、登录限流、TOTP 2FA、Token 刷新与退出
2. 个人中心：个人资料编辑、头像上传、修改密码
3. 动态菜单与按钮权限、数据权限（全部/本部门/本部门及以下/自定义）
4. 企业基础：部门、岗位、数据字典、参数配置
5. 租户隔离：不同租户登录后用户与文件数据相互隔离，配额与管理员可配置
6. 通知公告：最新公告、未读数、单条已读、全部已读、SSE Ticket 实时推送
7. 用户 Excel 导入导出、本地/MinIO 文件上传、文件管理页
8. 定时任务：创建、启停、手动执行、执行日志
9. 监控与告警：服务器监控、SQL 监控、在线用户、缓存、告警分级、静默期与 Webhook
10. 完整工作流：流程定义、审批节点、发起、待办、通过、拒绝、撤回、转办、审批日志
11. AI 任务：创建、状态轮询、结果查看、失败重试、取消
12. 前台官网：产品展示、解决方案、定价、预约演示表单
13. 部署与运维：全量中英文、暗黑模式、移动端响应式、Helm、CI/CD、冒烟与压测

## 4. 答辩预案

### 为什么 AI 服务独立部署？

AI 推理耗时且依赖 Python 生态，独立服务便于扩展算法和横向扩容，Java 只负责业务编排、任务状态机与回调幂等。

### 异步任务如何保证不丢不重？

任务号全局唯一，回调带 Token 校验，Java 侧状态机和幂等规则保证终态不重复写入；回调失败自动重试，Redis 持久化任务状态。

### 租户隔离是如何实现的？

登录后从当前用户提取 `tenantId` 写入 `TenantContext`，MyBatis-Plus 租户拦截器为业务表自动追加 `tenant_id` 条件；自定义 Mapper SQL 按需显式过滤，避免解析失败导致越权。

### 企业生产还缺什么？

生产环境可继续补充消息中间件、分布式事务、细粒度告警和容量规划；当前已具备安全、监控、CI/CD、租户与部署基线。
