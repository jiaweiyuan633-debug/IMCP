# 演示与答辩材料大纲

## 1. 项目定位

面向企业生产管理的双端脚手架：Java 业务后端 + Python AI 服务 + Vue3 管理端。

## 2. 功能演示

1. 登录：验证码、失败锁定、Token 刷新
2. 动态菜单与按钮权限、数据权限
3. 部门、岗位、字典、参数、租户管理
4. 用户 Excel 导入导出、文件上传
5. 定时任务创建、执行、日志
6. 服务器监控、SQL 监控、通知公告
7. AI 任务：摘要/关键词、状态轮询、失败重试、取消
8. 简化工作流：发起、通过、拒绝
9. 中英文切换、暗黑模式

## 3. 技术亮点

- JWT + Redis Token 管理、在线用户、登录安全基线
- RBAC + 数据权限 + 权限缓存
- Flyway 数据库版本管理、乐观锁、审计字段
- Quartz JDBC 持久化定时任务
- MyBatis SQL 监控、Prometheus 指标、traceId 链路
- FastAPI 异步任务 + Redis 状态机 + 回调重试
- Docker Compose / K8s 部署、CI/CD、冒烟与压测

## 4. 答辩预案

### 为什么 AI 服务独立部署？

AI 推理耗时且依赖 Python 生态，独立服务便于扩展算法和横向扩容，Java 只负责业务编排。

### 异步任务如何保证不丢不重？

任务号全局唯一，回调带 Token 校验，Java 侧状态机和幂等规则保证终态不重复写入；回调失败自动重试。

### 企业生产还缺什么？

生产环境可继续补充消息中间件、分布式事务、细粒度告警和容量规划；当前已具备安全、监控、CI/CD 和部署基线。
