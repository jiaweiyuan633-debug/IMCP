# 双端管理脚手架

前后端双端管理脚手架：Vue3 企业级管理后台 + Spring Boot 3 Java 后端 + FastAPI Python AI 服务。

## 仓库结构

```text
frontend/    Vue3 + TypeScript + Ant Design Vue 4 前端
backend/     Spring Boot 3 + MyBatis-Plus + Flyway Java 后端
ai-service/  FastAPI + Redis 异步任务 AI 服务
docs/        接口、数据库、部署文档
docker/      Docker Compose 交付配置
```

## 快速开始

见 `docs/deploy/` 与各服务目录中的说明。默认管理员：`admin`。
